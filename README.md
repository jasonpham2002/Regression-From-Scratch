# Linear Regression and Logistic Regression from Scratch
- Replicating a simple version of the linear regression class in Scikit-learn
- Include fit() and predict() methods
- Apply knowledge with gradient descent, cost function
- EDA, data preparation, scaling on Kaggle Dataset

## Linear Regression From Scratch
- Cost function MSE
- Gradient descent to find the point of convergent (or the local minimal)
- Compare trained weights between the model and that of Scikit-learn
- Graphed the change over cost of the model through each gradient descent iteration

## Logistic Regression From Scratch

- Binary classification implementation
- Sigmoid activation function for probability predictions
- Log loss (binary cross-entropy) cost function
- Gradient descent optimization
- Model evaluation with accuracy, precision, recall metrics
- Comparison with Scikit-learn's Logistic Regression
